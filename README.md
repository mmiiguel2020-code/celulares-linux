# celulares-linux

Investigación de celulares económicos (2017+) desbloqueables para correr
Linux libre (postmarketOS / Droidian / Ubuntu Touch) y usarlos como
"placas Pi/Teensy" sin restricciones.

- Doc principal: `docs/INVESTIGACION_CELULARES_LINUX.md`
